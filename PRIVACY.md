# Privacy

The browser and CLI run locally with no telemetry, analytics, cookies, accounts, remote APIs, or persistence. URLs are parsed as text and never fetched. Reports contain finding codes and paths, not submitted values. GitHub Pages receives ordinary access metadata when the hosted demo is used.

Use only synthetic event data and redacted signature markers. Never provide signing secrets, tokens, credentials, production comments, personal data, or regulated data. Secret-key detection is intentionally incomplete. Reload/close the page and remove local files to delete local input.
